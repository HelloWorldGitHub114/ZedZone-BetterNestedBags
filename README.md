# Better Nested Bags / 更好的套包

《隔离区》（ZED ZONE）纯客户端多层嵌套背包（包中包）全链路增强模组（BepInEx 6 IL2CPP，MIT 开源）。

## 缘起与致谢

感谢此前社区中套包模组作者为《隔离区》玩家带来的便利与启发。由于原模组目前在创意工坊已经下架，且日常游玩中仍存在套包物品放入快捷栏无法直接使用、以及部分建造模组联动扣料异常等痛点，本项目基于游戏本体从零独立编写并遵循 MIT 协议开源，分享给同样有需要的玩家使用。

## 核心功能

1. **建造、体素建造、维修与消耗全递归（原生防双倍扣料）**
   - 建造家具/建筑、体素墙体建造、维修锤维修、任务物品交付均直接统计并扣除套包内的材料。
   - 保留原版“先表层、后套包”的消耗顺序，并采用 **低优先级增量差额补扣 + 防重入保护**：只有当表层及前置流程未扣足所需数量时，才从嵌套子包补扣剩余差额，原生避免与其他建造/工具类模组叠加时出现双倍扣材料问题。
   - 扣料或移除套包物品后自动同步刷新角色总负重。

2. **快捷栏套包物品直接使用与实时刷新**
   - 直接按下快捷键即可使用放在套包内的药品、绷带、饮料、食物（支持区分生熟/烹饪状态）、投掷物（手雷/燃烧瓶等），并支持通过普通物品快捷槽直接切换装备套包或口袋里的近战/远程武器。
   - 补齐可烹饪食物在套包中的快捷栏总数统计。
   - 自动递归监听所有随身子背包（包括新拖入的套包）的变更事件，放入、取出或消耗物品时快捷栏角标即时更新。

3. **制作台、熔炉与烹饪原料穿透**
   - 工作台、熔炉与便携烹饪直接读取随身套包中的原料与工具，并精确保持“身上/附近”统计分界线。
   - 可选穿透附近储物箱内的套包子包（默认开启，可在配置中随时关闭）。
   - 取消制作时正确向套包内工具返还预扣耐久。

4. **商人交易与批量售卖**
   - 与商人交易时，自动识别套包内的货币、以物易物所需物品以及可批量出售的战利品。
   - 与同系列《智能背包 / Smart Inventory》的物品收藏锁完全兼容，保护套包内已收藏物品不被误卖。

5. **换弹、装箭、医疗包扎、右键工具与任务进度同步**
   - 散装子弹/霰弹、箭矢、弩箭放在套包或弹药袋中可直接换弹并在 HUD 正确显示余弹总数。
   - 医疗包扎、右键开罐器/打火机/缝纫工具/撬锁与破门工具/拆解工具、连续部署物品全面识别套包（同时支持识别已打开外部箱子内的套包工具）。
   - 物品直接放入随身嵌套子包时，同步触发收集类任务进度更新。

## 多人联机与兼容性

- **纯客户端模组（Client-Side Only）**：单人模式直接生效；多人联机时仅需本地玩家安装即可使用，无需服务端/房主强制安装。
- **防死循环与性能安全**：内置 IL2CPP 指针去重与可配置最大递归深度（默认 `12` 层），杜绝循环嵌套卡顿。
- **干净配置与卸载**：配置文件位于 `BepInEx/config/zedzone.betternestedbags.cfg`，全部功能模块均可单独开关；移除模组不影响原版存档读取。

## 推荐搭配同系列模组

- **智能背包（Smart Inventory）**：提供物品收藏防误删/误卖/误存、容器分类与指定物品过滤器、自定义拾取优先级路由（支持把战利品自动分拣进指定套包）。与《更好的套包》搭配实现“自动进包 + 随时直接用”的完整闭环。
- **更好的换弹（Better Reload）**：全面优化枪械换弹与弹匣操作体验（Steam Workshop ID: `3842785960`）。

## 构建说明

```powershell
# 自动探测 Steam 中的 ZED ZONE 目录并构建打包到 content/BetterNestedBags
pwsh -NoProfile -File .\build.ps1

# 构建并安装到游戏 Mods 目录（需先关闭游戏）
pwsh -NoProfile -File .\build.ps1 -Install

# 手动指定游戏安装路径
pwsh -NoProfile -File .\build.ps1 -GameDir "<你的 ZED ZONE 安装路径>"
```
